run_all.py 오케스트레이션 — CHUNK_SIZE(기본 100)건씩 ig/yt를 번갈아가며 classify → transform → resolve_links → load를 자동 반복. 한쪽 플랫폼이 다 끝나면 남은 플랫폼만 계속. 전 단계가 체크포인트 기반이라 Ctrl+C로 중단해도 재실행 시 이어서 진행됨.

동시성 — classify.py는 CONCURRENCY(API 호출만, 브라우저 없음), resolve_links.py는 RESOLVE_CONCURRENCY(워커마다 독립 Playwright 인스턴스).
